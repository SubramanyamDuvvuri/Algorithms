# 12 - Interview Readiness

Goal: become ready for coding, C++, system design, and behavioral interviews.

## Interview Types

Prepare for:

- C++ fundamentals.
- Data structures and algorithms.
- Object-oriented design.
- Multithreading.
- System design.
- Debugging and code review.
- Behavioral and project deep dives.

## Coding Interview Method

1. Restate the problem.
2. Ask clarifying questions.
3. Give examples.
4. Start with a brute force idea.
5. Improve complexity.
6. Write clean code.
7. Test edge cases.
8. Explain tradeoffs.

Clean communication is part of the score.

## C++ Interview Topics

Know:

- RAII.
- Rule of zero/five.
- Virtual destructors.
- Move semantics.
- Smart pointers.
- References vs pointers.
- `const`.
- Templates.
- STL containers.
- Iterator invalidation.
- Undefined behavior.
- Memory model basics.
- Mutex vs atomic.

## System Design Interview Topics

Know:

- API design.
- Data modeling.
- Load estimation.
- Caching.
- Queues.
- Database choice.
- Sharding.
- Replication.
- Rate limiting.
- Consistency.
- Observability.
- Disaster recovery.

## Behavioral Stories

Prepare stories for:

- Hard bug.
- Technical disagreement.
- Project you led.
- Missed deadline.
- Production incident.
- Refactoring tradeoff.
- Learning something difficult.
- Mentoring or helping someone.

Use STAR:

- Situation.
- Task.
- Action.
- Result.

## Weekly Mock Loop

Each week:

- 2 timed coding problems.
- 1 C++ deep dive.
- 1 system design.
- 1 project explanation.
- 1 retrospective on mistakes.

## Drills

1. Explain RAII in 90 seconds.
2. Design an LRU cache in code, then discuss thread safety.
3. Design a URL shortener in 35 minutes.
4. Debug a deadlock from a small code sample.
5. Explain your capstone project at three levels: recruiter, engineer, staff engineer.
