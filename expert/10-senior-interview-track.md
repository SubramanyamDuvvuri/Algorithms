# 10 - Senior Interview Track

Goal: prepare for interviews that test depth, tradeoffs, and ownership.

## C++ Deep-Dive Prompts

Practice explaining:

- RAII for files, locks, sockets, threads.
- Rule of zero/five.
- Move semantics and moved-from states.
- Virtual dispatch and object layout.
- Template instantiation and concepts.
- Allocators and memory resources.
- Iterator invalidation.
- Exception safety.
- Data races and memory model.
- Mutexes vs atomics.

## Coding Interview Prompts

Implement cleanly in C++:

- LRU cache.
- Thread-safe blocking queue.
- Segment tree.
- Trie autocomplete.
- Dijkstra with path reconstruction.
- Topological sort with cycle report.
- Parser for arithmetic expressions.
- Rate limiter.
- Order book.
- Mini key-value store.

## System Design Prompts

Design:

- Distributed cache.
- Metrics ingestion system.
- Feature flag platform.
- Low-latency trading gateway.
- File storage service.
- Notification system.
- Stream processing engine.
- Search autocomplete service.

## Senior-Level Evaluation

Interviewers look for:

- Clear requirements thinking.
- Tradeoff honesty.
- Good defaults.
- Correctness under failure.
- Testing strategy.
- Production awareness.
- Communication.
- Ability to simplify.

## Weekly Mock

- 1 C++ internals deep dive.
- 2 DSA timed problems.
- 1 concurrency problem.
- 1 system design.
- 1 architecture review.
- 1 behavioral story.
