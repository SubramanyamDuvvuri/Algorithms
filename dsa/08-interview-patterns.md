# 08 - Interview Patterns

Goal: build recognition speed without memorizing answers.

## Pattern Map

Use:

- Two pointers: sorted arrays, pairs, partitions, palindrome.
- Sliding window: substrings, subarrays, rate windows.
- Prefix sums: range queries, subarray sums.
- Hash map: counting, indexing, dedup.
- Stack: monotonic stack, parsing, next greater element.
- Heap: top k, streaming median, scheduling.
- Binary search: sorted data, answer space, monotonic predicate.
- BFS: shortest path with equal weights.
- DFS: backtracking, components, cycle detection.
- Topological sort: dependency ordering.
- DSU: dynamic connectivity.
- Trie: prefix matching.
- DP: optimal substructure and overlapping subproblems.

## C++ Interview Style

Use:

- Clear function signatures.
- `const` where appropriate.
- `std::vector`, `std::string`, `std::unordered_map`, `std::queue`, `std::priority_queue`.
- Avoid clever template code in timed interviews unless needed.
- Explain ownership if using pointers.

## Timed Progression

Beginner speed:

- Solve easy in 25 minutes.
- Solve medium in 45 minutes.

Strong speed:

- Solve easy in 10 minutes.
- Solve medium in 25 to 35 minutes.
- Produce tests without prompting.

Senior signal:

- Discuss edge cases.
- Discuss complexity.
- Discuss production concerns.
- Identify when the interview solution would not be production-ready.

## Brutal Weekly Set

Each week solve:

- 2 array/string.
- 1 hashing.
- 1 tree.
- 1 graph.
- 1 DP.
- 1 design/data-structure implementation.
- 1 concurrency/C++ deep dive.

Rewrite the two worst solutions cleanly.
