# Lesson 8 - Inheritance, Runtime Polymorphism, and Slicing

## Objective

Master inheritance, runtime polymorphism, and slicing well enough to implement, test, review, benchmark, and explain production code.

## Theory

Substitutability, virtual dispatch, vtables as an implementation model, `override`, `final`, abstract interfaces, slicing, and virtual destructors.

## Engineering Lab

Implement a message processor using virtual interfaces and again with `variant`; test destruction through base pointers and cloning.

## Required Evidence

Submit working C++20 code, focused tests, invariant and complexity notes, failure analysis, benchmark evidence where performance is relevant, and a short design review recording rejected alternatives.

## Mastery Gate

Defend inheritance versus composition and the base-destructor contract.
