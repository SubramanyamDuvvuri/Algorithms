# Lesson 19 - Implementing Core Data Structures

## Objective

Master implementing core data structures well enough to implement, test, review, benchmark, and explain production code.

## Theory

Dynamic array, intrusive list, open-address hash table, binary heap, BST, red-black tree, trie, and LRU cache.

## Engineering Lab

Implement all eight without STL storage shortcuts. Add invariant checks, exception guarantees, complexity tables, randomized differential tests, and adversarial workloads.

## Required Evidence

Submit working C++20 code, focused tests, invariant and complexity notes, failure analysis, benchmark evidence where performance is relevant, and a short design review recording rejected alternatives.

## Mastery Gate

Derive real worst/average/amortized behavior from each representation.
