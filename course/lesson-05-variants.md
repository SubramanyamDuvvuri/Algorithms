# Lesson 5 - Unions, Variants, and Tagged State

## Objective

Master unions, variants, and tagged state well enough to implement, test, review, benchmark, and explain production code.

## Theory

Shared union storage, active-member lifetime, manual tagged unions, `std::variant`, `get_if`, and exhaustive `visit`.

## Engineering Lab

Implement an expression AST and protocol state machine with `variant`; then implement a manual tagged union to expose the machinery.

## Required Evidence

Submit working C++20 code, focused tests, invariant and complexity notes, failure analysis, benchmark evidence where performance is relevant, and a short design review recording rejected alternatives.

## Mastery Gate

Compare variant and virtual dispatch in layout, safety, openness, and cost.
