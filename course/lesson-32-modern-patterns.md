# Lesson 32 - Modern C++ Design Patterns

## Objective

Master modern c++ design patterns well enough to implement, test, review, benchmark, and explain production code.

## Theory

Template strategy, variant visitor, observer, factory, type erasure, `std::function`, compile-time/runtime polymorphism, and obsolete classic patterns.

## Engineering Lab

Implement one pricing engine four ways; build a thread-safe event bus with subscription RAII and safe unsubscribe during dispatch.

## Required Evidence

Submit working C++20 code, focused tests, invariant and complexity notes, failure analysis, benchmark evidence where performance is relevant, and a short design review recording rejected alternatives.

## Mastery Gate

Select patterns from real change vectors, costs, lifetimes, and ABI constraints.
