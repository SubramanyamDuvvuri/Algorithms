# Lesson 21 - Dynamic Programming and Greedy Algorithms

## Objective

Master dynamic programming and greedy algorithms well enough to implement, test, review, benchmark, and explain production code.

## Theory

Memoization, tabulation, knapsack, edit distance, LIS, interval scheduling, bitmask DP, greedy proofs, and counterexamples.

## Engineering Lab

Implement reconstruction-capable edit distance, O(n log n) LIS, weighted interval scheduling, and assignment DP.

## Required Evidence

Submit working C++20 code, focused tests, invariant and complexity notes, failure analysis, benchmark evidence where performance is relevant, and a short design review recording rejected alternatives.

## Mastery Gate

Derive state and recurrence before code; disprove an incorrect greedy rule.
