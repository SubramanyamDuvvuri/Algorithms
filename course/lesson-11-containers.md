# Lesson 11 - Containers and Iterator Invalidation

## Objective

Master containers and iterator invalidation well enough to implement, test, review, benchmark, and explain production code.

## Theory

`vector` growth, `deque`, maps, unordered maps, sets, load factors, locality, stability, and invalidation rules.

## Engineering Lab

Benchmark operations and memory; create an invalidation matrix; choose containers for timers, LRU, symbol table, and order book.

## Required Evidence

Submit working C++20 code, focused tests, invariant and complexity notes, failure analysis, benchmark evidence where performance is relevant, and a short design review recording rejected alternatives.

## Mastery Gate

Predict pointer/reference/iterator validity after every mutation.
