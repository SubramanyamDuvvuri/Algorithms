# Lesson 15 - Advanced Generic Programming

## Objective

Master advanced generic programming well enough to implement, test, review, benchmark, and explain production code.

## Theory

SFINAE, tag dispatch, traits, CRTP, expression templates, policy design, customization points, and type erasure.

## Engineering Lab

Implement a type-erased callable and storage backend with value semantics; compare templates, virtual dispatch, CRTP, and erasure.

## Required Evidence

Submit working C++20 code, focused tests, invariant and complexity notes, failure analysis, benchmark evidence where performance is relevant, and a short design review recording rejected alternatives.

## Mastery Gate

Choose a dispatch mechanism from boundary and change requirements.
