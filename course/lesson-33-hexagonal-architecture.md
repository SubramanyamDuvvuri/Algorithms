# Lesson 33 - Hexagonal Architecture Without a Framework

## Objective

Master hexagonal architecture without a framework well enough to implement, test, review, benchmark, and explain production code.

## Theory

Domain core, ports, adapters, dependency injection, repositories, transaction boundaries, test seams, separation, and composition roots.

## Engineering Lab

Build order management with in-memory/file adapters, CLI transport, fake clock, and deterministic tests; domain headers may not depend on infrastructure.

## Required Evidence

Submit working C++20 code, focused tests, invariant and complexity notes, failure analysis, benchmark evidence where performance is relevant, and a short design review recording rejected alternatives.

## Mastery Gate

Draw compile dependencies and prove all arrows point toward policy.
