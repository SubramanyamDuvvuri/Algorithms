# Lesson 6 - References, Value Categories, and Lifetime

## Objective

Master references, value categories, and lifetime well enough to implement, test, review, benchmark, and explain production code.

## Theory

Lvalue/rvalue references, const correctness, value categories, temporary materialization, lifetime extension, and dangling.

## Engineering Lab

Build a view-based tokenizer, remove every dangling view, and review ten reference/view-returning APIs with written lifetime contracts.

## Required Evidence

Submit working C++20 code, focused tests, invariant and complexity notes, failure analysis, benchmark evidence where performance is relevant, and a short design review recording rejected alternatives.

## Mastery Gate

Classify each expression and justify every binding and lifetime.
